# TrustMesh Contracts

Solidity smart contracts for on-chain proof verification. Stage 0 Foundry scaffold only.

## Setup

```bash
forge install foundry-rs/forge-std OpenZeppelin/openzeppelin-contracts --no-commit
forge test
```

## Network

Sepolia testnet configuration is defined in `foundry.toml`. Set `SEPOLIA_RPC_URL` and `ETHERSCAN_API_KEY` in your environment for deployment stages.
